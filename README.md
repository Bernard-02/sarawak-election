# 砂拉越州選選民參考

給砂拉越選民的中文投票參考，對象是首投族和人在外地的游子。
第 13 屆砂拉越州選在 2026 年 12 月 12 日投票。

網頁：https://bernard-02.github.io/sarawak-election/

## 這是什麼

- 個人整理的非官方資料，不隸屬任何政黨，也不建議你投給誰。
- 每一項說法都附上來源連結。屬於批評的內容，都註明是誰說的。
- 資料由 Claude（AI）協助蒐集與整理，可能有疏漏。日期、選區、候選人與投票方式，一律以選委會（SPR）公布為準。

## 內容

| 分頁 | 內容 |
| --- | --- |
| 總覽 | 重要日期、倒數、目前的議席分布 |
| 新手指南 | 這場選舉在選什麼、投票日的流程、常見名詞 |
| 我的選區 | 82 個州選區查詢 |
| 政黨 | 各政黨的現況、說法、受到的批評 |
| 議題對照 | 按議題並排比較各黨 |
| 承諾查核 | 砂盟 2021 年 34 項承諾，逐項查到的紀錄 |
| 海外投票 | 郵寄投票的申請方式與期限 |
| 關於 | 整理原則、全部來源 |

## 回報錯誤

開一個 [issue](https://github.com/Bernard-02/sarawak-election/issues)，附上你看到的來源連結。
每一次更正都會留在這個 repo 的修改紀錄裡。

## 檔案

- `index.html`：網頁本體，由 `src/` 產生，不要直接修改。
- `src/template.html`：版面與頁面邏輯
- `src/style.css`：樣式
- `src/data.js`：選區、政黨、議題、來源
- `src/pledges.js`：承諾查核與新手指南的來源
- `src/build.py`：把上面四個檔案合成 `index.html`

```
cd src && python3 build.py
```
